This handbook covers **agno 0.3.7**. It starts with installation and then walks through the content model, the template system and the build pipeline. Each chapter stands on its own, but reading them in order is the fastest path if you are new.

> agno is a content-first static site generator. It is not an application framework, a JavaScript island runtime, a bundler or a plugin system. That boundary is what keeps the binary small and builds predictable.
