Why agno

Small surface, serious speed.

Everything a blog, documentation site or notes archive needs is built in. Everything it does not need stays out.

Fast by default

Every stage, from Markdown parsing to output writes, runs in parallel with Rayon. 1,000 posts build in about 106 ms cold.

Incremental by default

A fingerprint is stored per page. Only pages whose source, templates or site-wide context changed are rendered again.

One static binary

4.2 MB with no runtime dependencies. No node_modules, no language runtime, no service to install.

Batteries included

Sections, pagination, tag and category pages, RSS, sitemap, search index, 404, table of contents, syntax highlighting and live reload.

MiniJinja templates

Familiar Jinja syntax: extends, blocks, loops and filters. HTML autoescaping is on by default.

Content-first by design

No JavaScript islands, bundler, plugin system or theme marketplace. A small surface means a portable binary and predictable builds.

Cold build times

Same hardware, same corpus.

Intel i5-13420H, 12 threads, CachyOS. The output directory is removed before every run and process startup is included.

Authoring

Write Markdown. The template does the rest.

TOML or YAML frontmatter, optional template overrides, and fields for slugs, dates and tags. Unknown fields reach templates through page.extra.
